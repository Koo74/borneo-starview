An advanced stargazing site selector for **Sabah & Sarawak, Malaysia (Borneo)**. Find the best dark-sky locations, check real-time haze conditions, and plan your next astrophotography session in Borneo's pristine rainforests and highlands.

---

## ✨ Features

- 🗺️ **200+ locations** across Sabah & Sarawak
- 🌫️ **Haze & fog detection** — distinguishes natural mountain fog from smoke haze
- 💨 **Live air quality** — PM2.5, PM10, AQI from Open-Meteo CAMS model
- 🏞️ **16 protected dark-sky zones** — Mount Kinabalu, Maliau Basin, Bario Highlands, Mulu, etc.
- 🌙 **Moon phase** & **Milky Way visibility** calendar
- 📸 **Activity-specific scores** — naked-eye / telescope / astrophotography
- 📊 **Export reports** — CSV + JSON with full data audit trail
- 🧠 **Agent memory** — remembers previous analyses, learns optimal parameters
- 🗺️ **Interactive map** — click any point, get instant analysis
- 🌡️ **High-altitude fog detection** — for Mount Kinabalu summit conditions
